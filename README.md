# Comet

A Minecraft Java client and launcher for Windows, Linux and macOS.

- Built-in PvP instances for **1.7.10** and **1.8.9**, plus **1.16.1** speedrunning.
- Custom instances with vanilla, Fabric or Quilt; Modrinth modpacks and Prism-compatible imports.
- In-game mods, customizable HUDs and presets. Press **Right Shift** to open the mod menu.

Requires a Minecraft: Java Edition account. Java runtimes are downloaded automatically. OptiFine is downloaded separately, never bundled.
